Contributed tunes for RTX 3090, RTX 5090, A100 and B300 live here as `<gpu>--<cpu>--<search>-<sha8>.json`. Run `cmt export ~/.cache/cmt/tune.json --out my-tune.json`, then open a pull request adding the export at the path it prints. Exports keep selected settings, hardware models and performance summaries, leaving out raw logs and machine identifiers; CPU and GPU models must match when loading one with `cmt run --config tunes/FILE.json -- APP`. Local tuning with `cmt tune -- APP` is the simplest way to get settings for your own machine.
